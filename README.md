# Valorant Roaster

A full-stack web application that fetches a player's Valorant statistics and delivers a personalized, humorous "roast" based on their Rank, K/D ratio, and main Agent.

## About The Project

This isn't meant to be a groundbreaking or highly complex application. It is actually my very first project uploaded to GitHub! I built this primarily as a learning experience to expand on what I was taught at university. 

My main goals for this project were:
* **Transitioning to TypeScript:** I had only worked with vanilla JavaScript in my university courses, so I wanted to challenge myself and see how TypeScript works in a real project.
* **API Integration:** I wanted hands-on practice with fetching, parsing, and handling live data from a third-party external API.
* **Backend Basics:** I wanted to learn how to set up a basic backend server, handle CORS, and serve frontend files using Node.js and Express.

## Tech Stack
* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express, TypeScript
